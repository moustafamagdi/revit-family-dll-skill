## Intended use

This package guides an assistant in preparing C# generator DLLs for parametric
Autodesk Revit families. It includes supporting files and a synthetic starter.
It is not a ready-made manufacturer family library or an engineering certification.

The bundled starter targets Revit 2024 / .NET Framework 4.8 / x64. Other releases
require suitable changes and validation. You supply appropriately licensed Revit,
matching API assemblies, templates, Add-in Manager, and build tools as needed.
Autodesk software and manufacturer documents are not licensed by this package.

## Inputs, outputs, and testing

Provide only documents and other material you have permission to use. Review
dimensions, assumptions, geometry, parameters, connectors, and generated files
for your intended use. A successful compilation does not establish successful
operation inside Revit. Test generated DLLs and families before relying on them
in a production project, and retain suitable backups of your work.

The workflow respects the instructions and permissions you give the assistant.
Running a generated DLL, installing an add-in, and changing a Revit model are
separate actions from preparing source and compiling a DLL.
