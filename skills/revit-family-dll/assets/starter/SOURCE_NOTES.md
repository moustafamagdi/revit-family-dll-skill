- Native rectangular solid: fixed width 200 mm, fixed depth 150 mm.
- Three synthetic types: H0300, H0600, H0900; default heights 300, 600, 900 mm.
- `Demo_Height` is a type length parameter associated with extrusion end.
- X/Y profile is fixed, centred on the insertion origin; base elevation is zero.
- Height flex check: each type's default plus 25 mm, then restored.
- No connectors, physical system performance, materials, or network tests.
- Template: user-selected Revit 2024 Generic Model RFT, expected empty of forms.
- Intended run: create, validate, restore, save, close, reopen, validate again.
